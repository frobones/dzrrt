# 3D anatomy models

Web-ready models of the bones, muscles, joints and muscle attachments, used by the
site's 3D views.

| File | Contents |
| --- | --- |
| `bones.glb` | The skeleton, one node per bone |
| `muscles.glb` | Skeletal muscles, one node per muscle, part or head |
| `joints.glb` | Ligaments, joint capsules, menisci and intervertebral discs |
| `attach.glb` | Origin and insertion surfaces on the bones |
| `muscle-map.json` | Maps each muscle on the site to its model nodes and attachment surfaces |

The files are generated by `tools/anatomy/export_models.py` and
`tools/anatomy/map_muscles.py` (see the docstrings for how to run them). They are
simplified and Draco-compressed.
